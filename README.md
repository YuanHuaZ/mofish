# 摸鱼小游戏合集

六款单机小游戏打包在**同一个 exe** 里，启动后先在「游戏大厅」选游戏，全程离线、零依赖。
每款游戏各自一个文件夹，都带自己的引擎、题目/关卡数据和启动器 —— 既能单独运行，也能从大厅进入。

```
摸鱼游戏合集.exe        ← 双击即用（自带 Python + Qt，无需安装任何环境）
启动游戏合集.bat        ← 有 exe 就开 exe，没有就用本地 Python 跑源码
```

## 局域网联机（象棋 / 五子棋）

同一局域网内两台电脑（或同一台机的两个窗口）即可对战，**不需要服务器、不需要联网、不需要额外依赖**：

1. 双方分别打开「中国象棋」或「五子棋」（游戏和版本要对上）；
2. **房主**点右侧「创建 / 加入房间」→ 选「我执黑方 / 红方」→ 点**创建房间**，
   面板上会显示本机地址；
3. **另一方**打开同一个对话框，右侧**会自动列出同一局域网里的房间**（房主昵称 + 状态），
   选中后点「加入选中的房间」即可；也可以让他手动填 IP 后点「加入」。

> 首次运行 Windows 会弹防火墙提示，**要选「允许访问」**（专用网络即可），否则对方发现不了你。
> 房间广播用 UDP，走棋用 TCP；默认端口 象棋 `45680/45682`、五子棋 `45680/45681`，
> 被占用时会自动改用随机端口（此时请让对方从自动发现的列表进入）。

联机对局中的规则：

- 只能在自己回合落子，对方回合棋盘会锁定；
- **悔棋**：发起方请求 → 对方弹窗确认；双方按同一规则回退（撤到发起方重新可下为止），
  所以两边棋盘始终一致；
- **再来一局**：点「重开」向对方发起邀请，接受后**自动交换先手方**；
- **认输**：象棋 / 五子棋都有，认输后本局判负；
- 对方掉线或关窗口会立刻提示，随后自动回到人机模式；联机战绩不会混进人机统计。

也可以被大厅用 `importlib` 动态加载（包内路径如 `klotski.klotski_app`），互不干扰。

## 存档

所有进度、战绩都收在 **exe（或项目根目录）同级的 `saves/` 文件夹**里，不会散落在外面：

```
saves/
├── sudoku_save.json     klotski_save.json     number_save.json
├── xiangqi_save.json    gomoku_save.json      point24_save.json
```

删掉整个 `saves/` 文件夹即可重置全部记录；只删其中某个文件，就只重置那一款游戏。
若 exe 所在目录不可写（例如放在只读盘），会自动退回 `%APPDATA%` 下的 `saves/`。

> 从旧版本升上来的话不用担心：首次运行时，会自动把散落在 exe 同目录的 `*_save.json` 搬进 `saves/`，进度不丢。
> 自检产物（截图 / 日志）另外放在 `_selftest/`，不会混进存档目录。

## 从源码运行 / 打包

```bash
# 运行（需要 PySide6）
python main.py

# 单独运行某一款游戏
python klotski/klotski_app.py

# 自检：跑一遍全部游戏，做引擎校验并给每款游戏截图
python main.py --selftest        # 结果写入 selftest.log 与 selftest_shots/

# 重新生成题库
python klotski/build_levels.py        # 30 关，多进程 BFS 验证可解，约 20 秒
python numberklotski/build_levels.py  # 15 关，难度分严格递增，约 8 秒
python point24/build_puzzles.py       # 枚举 1820 种组合并按难度分 5 档，约 3 秒

# 打包单文件 exe
python build_exe.py
```

## 实现备注

- **难度可复现、可验证**
  - 数独：题库构建期预生成，难度分 = 空格数 + 技巧加成。
  - 华容道：每关的最优步数由 BFS 精确求解（同形状棋子等价，约 2.6 万状态）并写进题库；
    15 个新关卡由程序随机生成后逐个验证可解。
  - 数字华容道：难度分 = 初始曼哈顿距离 × 尺寸系数，构建期在数百个候选中挑最接近目标的一局，
    并强制难度分严格递增；打乱方式为「从已解局面走随机合法步」，天然保证一定有解。
  - 24 点：枚举 1~13 的全部 1820 种组合（1362 种可解），难度分 = (可用第一步走法数之差)×3，
    必须用分数解的再加 50；运行时按档位随机抽题，因此是**无限关**。
- **规则正确性**：象棋走子生成用标准 perft 校验 —— 初始着法 **44**、perft(2) **1920**、perft(3) **79666**，全部吻合；
  24 点用 Fraction 精确计算，`1 3 4 6` 解出唯一解 `6÷(1-3÷4)`。
- **输入尽量宽容**：24 点的算式支持 `+ − × ÷` 与 `+ - * /`（`x`、全角 `＊＋－＝` 也认），可加括号。
- **联机协议**：TCP 长连接 + 按行分隔的 JSON，消息有 `move / undo_req / undo_ok / rematch_req /
  rematch_ok / resign / ping / bye`；房主用 UDP 广播（同时发给 `255.255.255.255` 和 `127.0.0.1`，
  所以同一台机开两个窗口也能互相发现）宣告房间，加入方监听即得房间列表。
  收发都在后台线程、按 Qt 信号回主线程；带心跳保活（≈5 秒）与 26 秒空闲超时，
  拔网线/关窗口都能立刻感知。悔棋与再来一局是「请求—同意」式，
  两边用同一条确定性规则计算回退步数，保证棋盘永远一致。
- **不卡界面**：象棋 / 五子棋的 AI、华容道的 BFS 求解器都在后台线程里跑，并带世代号防护，
  切关卡或关窗口时不会把过期结果写进新对局，关闭窗口前会等待线程结束。
